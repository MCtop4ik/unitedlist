# PRD — GD United List

## 1. Идея

GD United List — объединённый демонлист для Geometry Dash. Вместо того чтобы ходить по нескольким спискам, пользователь видит все уровни в одном каталоге: от топ-1 демонов Pointercrate до остальных уровней GDDL за пределами топ-150.

Списки различаются правилами и масштабом, поэтому проект не пытается свести их в одну плоскую таблицу «на глаз». Он сохраняет принадлежность уровня к источнику (зоне).

## 2. Проблема

- Уровней 10 000+, и они разбросаны по нескольким спискам с разными правилами.
- Сложно понять, где уровень находится относительно остальных, если он есть только в одном из списков.
- Нет единого места, где видно свой прогресс, статистику и прохождения других игроков.
- Информация об уровне (автор, сложность, видео, превью) лежит в разных источниках.

## 3. Цели

1. Единый каталог демонов с поиском, фильтрами и сортировкой.
2. Четыре зоны, отражающие происхождение уровней.
3. Общий вид ALL, где уровни отранжированы по сложности.
4. Личный кабинет: профиль, прогресс и прохождения.
5. Список игроков, прошедших уровень, с информацией о них и прогрессе.
6. Данные об уровнях подтягиваются из внешних источников и кешируются.

## 4. Не цели (на старте)

- Собственный редактор правил демонлиста и модерация заявок.
- Замена Pointercrate/AREDL/GD Ladder как источника истины.
- Мобильное приложение и публичное API для сторонних клиентов.
- Реалтайм-обновления и социальные функции сверх профиля и списков прохождений.

## 5. Пользователи и сценарии

| Пользователь | Сценарий |
|---|---|
| Игрок | Находит уровень, смотрит позицию, сложность, превью и прохождения |
| Игрок | Отмечает прогресс и видит свои прохождения |
| Гость | Листает ALL и зоны без регистрации |
| Модератор/владелец | Обновляет таблицу уровней в `data/` и данные о прохождениях |

Основные сценарии:

1. Открыть ALL, отфильтровать по сложности/зоне, найти уровень.
2. Открыть карточку уровня: позиция, зона, автор, сложность, превью, список прошедших.
3. Открыть профиль игрока: прохождения и прогресс.
4. Переключаться между зонами, не теряя контекст фильтров.

## 6. Зоны

Подробности — в `docs/ARCHITECTURE.md`.

- **ALL** — все уровни, отсортированные по сложности. Общий вид поверх зон.
- **Pointercrate zone** — топ-150 Pointercrate: `main` (1–75) и `extended` (76–150).
- **AREDL zone** — экстрим-демоны, кроме уже вошедших в топ-150.
- **GD Ladder zone** — все остальные уровни GDDL, не покрытые предыдущими зонами.

## 7. MVP

- Каталог уровней из `data/` с поиском, фильтрами и пагинацией.
- ALL и четыре зоны с корректной принадлежностью уровней.
- Карточка уровня: базовая информация, превью, прохождения.
- Профиль игрока и ручное/импортированное отслеживание прогресса.
- Кеш внешних запросов на бэкенде.

## 8. Данные и интеграции

- `data/` — таблица уровней: id, название, автор, зона, позиция, сложность, ссылки, флаг верификации и т.п.
- **boomlings.dev** — информация об уровнях Geometry Dash.
- **levelthumbs.prevter.me** — превью уровня, например `https://levelthumbs.prevter.me/thumbnail/{levelId}/small`.
- **Pointercrate API** (`https://pointercrate.com/api/v2/`, документация: `https://pointercrate.com/documentation/index/`) — топ-150 и данные прохождений.
- **AREDL API v2** (`https://api.aredl.net/v2/api`, документация: `https://api.aredl.net/v2/docs`, OpenAPI: `https://api.aredl.net/v2/openapi.json`) — экстрим-демоны, позиции и прохождения.
- **GDDL API** (`https://gdladder.com/api`, документация: `https://registry.scalar.com/@gddemonladder/apis/gddl-api`) — все остальные уровни, их рейтинг и прохождения. GDDL используется для GD Ladder zone.

Внешние источники не являются частью клиента: фронтенд ходит только в наш бэкенд, бэкенд объединяет и кеширует ответы.

## 9. Технологии

- Бэкенд: Node.js (REST API, работа с `data/`, интеграции, кеш).
- Фронтенд: React.
- UI: Radix UI — базовые примитивы, доступность и поведение компонентов; визуальный слой поверх Radix.
- Монорепозиторий: `frontend/`, `backend/`, `data/`, `docs/`.

## 10. Метрики успеха

- Пользователь находит уровень за ≤ 3 действия.
- ALL и зоны открываются быстро при 10 000+ уровней (серверная пагинация, без загрузки всего списка).
- Нет дублей уровней между зонами (кроме осознанного пересечения в ALL).
- Данные карточки уровня совпадают с источником после обновления кеша.

## 11. Открытые вопросы

- Авторизация решена: собственные аккаунты с email и паролем, серверные сессии в SQLite.
- Формат ручного ввода прохождений и модерации на старте.
